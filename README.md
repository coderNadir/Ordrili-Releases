# Ordrili Releases

Public installers for the Ordrili restaurant platform.

| App | What it is | Downloads |
|---|---|---|
| **Ordrili Hub** | The restaurant's local server — install on the manager's computer. Keeps orders flowing during internet cuts and syncs to the cloud when the connection returns. | [macOS](https://github.com/coderNadir/Ordrili-Releases/releases/latest/download/Ordrili-Hub-mac.dmg) · Windows (soon) |
| **Ordrili Spot** | One app for every device — self-order kiosk, table tablet, waiter phone, kitchen screen, TV queue board. Connects to the Hub over the restaurant Wi-Fi. | [Android APK](https://github.com/coderNadir/Ordrili-Releases/releases/latest/download/Ordrili-Spot-android.apk) · [macOS](https://github.com/coderNadir/Ordrili-Releases/releases/latest/download/Ordrili-Spot-mac.dmg) · Windows (soon) |

Asset names are stable across releases — the `releases/latest/download/…` links above always serve the newest version. Current versions and release notes live in [`manifest.json`](manifest.json).

macOS note: builds are not yet notarized — on first launch, right-click the app → Open.
